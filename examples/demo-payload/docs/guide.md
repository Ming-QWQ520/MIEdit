# MIEdit Demo 使用指南

欢迎使用 MIEdit Demo！这是一个用于演示 MIEdit 安装器系统的示例应用。

## 包含内容

- `MIEditDemo.exe` —— 演示主程序
- `data/` —— 演示数据文件
- `docs/` —— 本文档
- `readme.txt` —— 根目录说明

## 卸载

在「设置 → 应用」中找到 MIEdit Demo，或使用开始菜单中的
「卸载 MIEdit Demo」快捷方式。卸载器会：

1. 删除安装期间写入的全部文件；
2. 移除开始菜单与桌面快捷方式；
3. 清理注册表卸载信息与自定义键；
4. 自动删除卸载器自身。
